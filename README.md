# The-Ultimate-Chase
<b>This is a maze game I made at Hack Club Haven. Get to the other character while avoiding the gray box!</b>
## Demoing and Editing
You can play the game [here](https://arnavshah100.itch.io/the-ultimate-chase). You can download the [build.zip](build.zip) folder and upload it to Godot to see and edit the behind-the-scenes part of the game.
