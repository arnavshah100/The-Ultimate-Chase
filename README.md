# The-Ultimate-Chase
<b>This is a maze game I made at Hack Club Haven. Get to the other character using the arrow keys while avoiding the gray box!</b>
## Demoing and Editing
You can play the game [here](https://arnavshah100.itch.io/the-ultimate-chase). You can download the [build.zip](build.zip) folder and upload it to Godot to see and edit the behind-the-scenes part of the game. The game loops, bouncing from one character to the other. The speed of the characters are set at random within an interval, making the game a little different each time it loops.
